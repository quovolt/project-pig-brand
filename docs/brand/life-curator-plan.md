# 生活主理人企划案

::: info 方案状态
本案说明拟开展的服务与经营原则。具体功能、溯源能力及履约安排仍需落实，以下内容不代表相关服务已上线。
:::

## 企划概述

「生活主理人」以一日三餐为起点，倡导主动安排、认真体验日常生活。企划拟通过小程序，将用户的饮食喜好、餐食计划、食材采购与烹饪准备连接起来，让生活安排从脑海中的想法变成可以逐步执行的计划。

用户是自己生活的主理人，平台承担成熟、稳重的合伙人角色：聆听需求、记录安排，并在适当的时候提供支持。企划鼓励提前规划，同时保留临时采购路径，照顾生活中的变化，让规划有秩序，也有余地。

## 需求与目标

本企划关注工作与日常采购之间的矛盾：下班后想做饭，却难以挑选到满意的新鲜食材；上班前购买，又不便妥善保存。同时，议价、采购沟通和复杂优惠规则也会占用用户的时间。

企划希望通过餐食规划、按需供给和透明定价，降低这些安排的负担，使用户能够从容地照顾自己、与家人朋友分享，并在一餐一饭中获得创造和体验生活的空间。

## 服务内容

小程序拟围绕「聆听、记录、适时提供」组织体验：

- **记录喜好与计划：**整理用户的饮食喜好、想尝试的菜谱和餐食安排。
- **提供烹饪准备支持：**在需要时提供烹饪方法、原料清单和预处理建议。
- **衔接采购与配送：**将餐食计划转化为食材需求，协助安排采购与配送时间。

这些交互旨在让用户持续参与生活的编排，形成日常的仪式感。具体记录范围和建议功能以实际产品设计与实现为准。

## 供给与履约路径

新鲜是本企划组织生鲜供给的基本要求。方案以提前预约为主线，以临时采购补充，两条路径分别说明来源及可掌握的信息。

### 提前预约

用户提前提出商品、数量和所需时间，平台据此协调自有产线分割，并按约定时段组织配送。

企划提出以大石 4A 屠宰场的自有产线作为预约供给基础，以全流程可追溯为建设目标，将来源、分割和订单信息衔接起来。具体可记录、核验及向用户展示的信息，需在履约系统中落实。

### 临时采购

对于临时起意或计划变更的需求，拟通过线下菜市场调配，或由专人前往屠宰场一级市场挑选配货。

本案中的「一级市场」指屠宰场内面向菜市场档主等采购方供应的铺位；「二级市场」指线下菜市场档口。临时采购无法像自有产线预约路径一样全流程监控，因此两条路径的来源说明和监控范围应清楚区分。

企划不以从下单到餐桌两小时内完成作为服务承诺。临时采购用于补充计划之外的需求，具体供应与配送安排仍需结合履约能力确定。

## 按需组织的运营机制

本企划采用用户需求与产能、采购资源相匹配的经营方式。「不设库存」指线上平台不为尚未产生的订单预留待售肉品。

1. **用户提出需求：**明确需要的商品、数量和时间。
2. **匹配供给：**预约需求对应自有产线，临时需求对应市场调配或采购。
3. **组织履约：**围绕订单安排分割、采购和配送。
4. **线下分流：**预约订单最终无法正常履约时，对应肉品拟流入线下菜市场肉档销售。

这一机制将提前规划与供应安排连接起来。用户下单后的订单确认条件，以及异常订单的处理规则，仍需在具体履约方案中明确。

## 日内固定挂牌价

本企划确定的定价原则是：同一天内挂牌价固定，用户在当天不同时间购买，适用相同的挂牌价格。即使当天采购成本上涨或单笔订单亏本，也不在同一天内反复调价，日内成本波动由经营方承担。

除前期引流促销外，不设置优惠券、满减等复杂促销机制，减少议价和计算优惠的负担，使用户无需为购买时机或凑单规则分心。

日内固定价不等于跨日固定价；不同日期之间的定价规则尚待明确。

## 实施范围

后续实施需落实小程序的记录与建议功能、两条供给路径的来源信息、预约溯源能力，以及订单确认和异常履约规则。服务范围和具体承诺应与实际具备的产品及履约能力一致。
