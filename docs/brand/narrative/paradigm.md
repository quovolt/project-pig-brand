# 藏锐路径：为消费者的好奇心分级

> 跨国集团不需要把整张集团架构图贴在广告牌上，只需安静露出一枚上市股票代码——愿意深究的人，自然会顺着线索往下看。

**藏锐路径**是 Project Pig 面向消费者的信息披露与叙事范式。核心做法只有一件事：**顺着消费者自然冒出来的好奇心，把信息分成清晰的层级，每一层只答当下那一个问题，同时留一枚克制的线索指向更深处——步步生花，把发现深度的功劳交还给愿意探索的人。**

## 为什么必须给好奇心分级

传统的生鲜与肉品习惯一股脑叫卖：人刚路过，就把「自有产线、检疫合格、新鲜便宜」全糊在脸上，像上一辈唠唠叨叨炫耀家底。结果最浅层的路人嫌烦，真正挑剔、想深挖的人又觉得你一眼就被看穿，毫无余味。

Project Pig 面对的是 **Generation Z**。我们不是升级版肉摊，而是想靠理念和「生活主理人」企划留住气味相投的人、拉高黏性与复购：

- **藏锐才是专业的代名词**：急着证明自己，反而显得心虚；只在人心里起疑、想确认的那一刻稳稳亮出真功夫，专业感才会自然立住。
- **反差带来信任**：Gen Z 见惯了「外面包装得天花乱坠，点进去全是空话和套路」。藏锐路径反过来——**外面越克制，越往里剥越是真材实料**，越往下探索信心越足。
- **停在哪一层都完整，多走一步就多开一朵花**：不想深究的人，只买一份肉就走，已经足够顺手；愿意多点一下的人，每往里走一层，都会收获一层新的笃定与惊喜。

## 两条真实入口，同一套纵深

现实里，消费者不会永远死板地从一级爬到五级，但无论从哪一端进来，五级结构都能稳稳接住：

- **产品切入（1 → 2 → 3 → 4 → 5）**：先被包装和审美吸引 → 下单发现没套路、挺顺手 → 扫一眼检疫合格证觉得干净 → 顺着加工地挖出 4A 自有产线惊叹专业 → 最后读懂「生活主理人」彻底留下来。
- **内容切入（5 → 1 → 2 → 3 → 4）**：先在朋友饭桌或内容里被《一顿还没写完的晚饭》打动 → 进小程序体验清爽下单 → 动心想常买时查验检疫与当日同价 → 挖出自有产线后把信任彻底锁死。

## 执行「藏锐路径」的四条铁律

1. **单层不越界**：绝不在第一级包装正面上硬塞第三级的检疫口号或第四级的屠宰场标语——不抢答消费者还没冒出来的问题。
2. **层间留暗扣（股票代码原则）**：每一层都在最自然的位置留一枚轻线索（角落编号、页面小字、检疫单里的加工地），不逼人点，但懂行的人一眼能顺藤摸瓜。
3. **退场完全自由**：任何人停在一、二级只买一块肉就走，体验都必须 100% 完整，绝不拿「必须看懂品牌故事」绑架消费。
4. **越深越坦诚**：面对满额、变更、临时采买与预约的差异，乃至目前命名与主标尚未定稿的现状，越往深处越直白说实话——真实本身就是最高级的质感。

## 落到具体触点上怎么用

- **肉品包装与标签**：正面极简清爽，只留品牌视觉、品名、份量与日期（一级/二级）；角落一枚克制的批次/溯源码，扫进去先见肉品合格证、检疫与来源说明（三级），顺着加工地再点一层，才展开大石 4A 自有产线与按需分割的故事（四级）。
- **小程序与商品页**：正常逛单清爽利落、顺手给做法灵感（二级）；点开「检疫与来源」或「今日价格说明」，安静展示合格凭证、来源区分与当日同价规则（三级）；想多了解的人，顺着线索进入自有产线与「生活主理人」世界（四级/五级）。
- **异常与变化通知**：出状况时，人此刻最想知道的就是「现在怎么了、我还能怎么办」——直给事实和真能选的方案，绝不藏匿限制，也不拿抒情盖住问题。
