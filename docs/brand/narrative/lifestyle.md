# 生活主理人与品牌气质

> 准备越周全，生活越自由。食材备妥了，这顿饭才刚开始。

很多人以为，把买肉搬到线上，就是换个地方吆喝——比谁更新鲜、比谁更便宜，催着人赶紧挑完结账。

Project Pig 不想做那种叫卖式的货架。我们更在意的是：**当你突然想认真吃顿饭时，身边有没有一个懂行、靠谱、又不替你做主的搭档。**

## 有准备的即兴

日子不是照着剧本演完的。有早就盼着的聚餐，也有突然插进来的加班；有兴致来了想试道新菜的晚上，也有累到只想煎两片肉配冰饮的时候。

如果所谓的「专业」，只是给你添一堆流程、让人更难改主意，那反倒把生活绑死了。我们更喜欢另一种状态——**有准备的即兴**：

- **准备归我们**：把食材、规格、价格和该担的责任打理清楚；
- **即兴归你**：按计划好好做，行；临时改口味、多添双筷子，或者干脆简单吃一口，也行。

## 「生活主理人」：帮你想着，但不替你做主

主品牌守住品质和信用；**「生活主理人」**是主品牌下的生活企划，像一个记性很好的厨房搭档：

- 记下你爱吃的部位、偏好的口味，还有某天刷到想试的菜；
- 你琢磨「这块肉还能怎么做」时，递上几个试过确实好吃的点子；
- 决定开火时，顺手把想吃的念头接成采购和准备。

你完全可以只买一份肉就走，这本身就足够完整；想把一餐过出点新花样时，我们一直都在。

## 需要时靠得住，平时不抢戏

我们把自己放在一个**懂行、有分寸的搭档**位置上——不端着架子教人过日子，也不在出状况时装看不见。

| 时刻               | 我们的分寸                                                                           | 这样说（对味）                                                             | 不这样说（失真）                                        |
| ------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------- |
| **想找做法灵感时** | **有主意，但不说教**<br>大胆勾起胃口和好奇，永远是「推荐试试」，不是「规定答案」。   | 「这块肉除了炒着吃，切厚片煎出焦边也很香——想换个口味的话，三步就能出锅。」 | 「懂生活的人都知道，好肉就该这样吃。」（爹味说教）      |
| **下单或开火时**   | **手脚利落，不抢戏**<br>信息一眼看清，用完就安静退开，不催打卡、不写小作文刷存在感。 | 规格、份量、当日价和可选时段写得明明白白，点完就能关掉页面。               | 满屏弹窗催收藏、凑满减、替你规划下一顿。（强行加戏）    |
| **满额或生变时**   | **不躲事，讲实话**<br>先把现状和真能选的方案摆出来，不甩锅、不画空饼。               | 清楚说明眼下怎么了、能怎么换；如果涉及日期或总价变动，先摊开再让你决定。   | 「亲亲别担心，我们一定竭尽全力为您兜底！」（空话/越界） |

## 画面与字体：放得开，也收得住

视觉跟说话一样，该热烈时放开，该让路时收住。

![早期三触点画板：左侧烹饪主画面，中间商品页，右侧服务界面](/b2/concepts/three-touchpoints.png)

- **留住认得出的生活，放开最值得想象的一处**：烹饪的手、锅和食材保持真实可辨，把看不见的香气、热气和动势交给金黄与橙红的暖色层。
- **不同地方用不同音量**：品牌主画面可以鲜活、大胆；到了商品和服务界面，色彩主动退到边上，把视线留给食材、价格和操作。
