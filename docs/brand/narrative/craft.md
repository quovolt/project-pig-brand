# 看不见的准备

> 有些功夫不必贴在门口叫卖，但当你想查、想问、想往下深挖的时候，每一层都应该接得住、经得起细看。

按照[藏锐路径](./paradigm)的五级好奇心阶梯，走到这一页的人已经越过了第一眼的审美与日常下单，开始进入**第三级「核验与安心」（查检疫、来源与价格规矩）**，再顺着加工线索往里走，看到**第四级「溯源与惊叹」（肉从哪加工、自有产线怎么运转）**。

下面不讲故事，按从「核验安心」到「自有产线」的顺序，如实交代我们的底盘与边界。

::: info 建设状态说明

## 一、三级核验：检疫、来源与价格规矩

当消费者想确认「这肉靠不靠谱、买得值不值」时，最该先摆在眼前的不是口号，而是清清楚楚的凭证与规矩：

### 1. 检疫与来源说明，两条路径绝不混淆

- **可核验的安心底线**：围绕肉品合格证、检疫信息、分割日期与规格建立清晰的展示标准，让想确认安全的人一眼查得到、看得懂。
- **预约与临采清楚分开**：提前预约路径与临时采购路径所掌握的监控深度不同，来源说明必须各自如实标注，绝不拿自有产线的溯源说法去套临时采买。

### 2. 当日固定挂牌价，不玩套路

定价只守一条朴素原则：**同一天内，挂牌价固定。**

- 当天不同时间下单，看到的是同一个实在价；即使当天上游采购成本波动，也不在一天内反复调价，日内波动由经营方承担。
- 除前期引流外，不设优惠券、满减、凑单等消耗精力的规则，不让人为「什么时候买最划算」分心。
- 同样把话说在前面：**日内固定挂牌价不等于跨日固定价或跨日价保**，不同日期之间的定价规则仍需结合实际运营明确。

### 3. 变化发生时的诚实边界

品牌愿意回应变化，但不空口答应「两小时必达」或「随时无条件改约」：

- **遇到选好的时段刚满额**：保留你已填的信息，只给出真实可选的替代时段；若更换选项会影响肉品日期或总价，先把差异摆清楚，再由你决定。
- **遇到状态未确认**：付款状态或新时段未落定前，界面绝不误导为「未扣款」或「改约成功」。
- **责任归属清晰**：因切割、出库、食安与配送限制而无法变更时，坦诚告知限制与原订单去向；若问题由我们造成，由我们承担相应责任。

## 二、四级溯源：肉在哪加工，自有产线怎么运转

顺着检疫和来源线索再往下追问「肉从哪加工出来的、为什么敢按需准备」，才真正展开我们压箱底的供给叙事：

- **大石 4A 屠宰场自有产线（提前预约主线）**：你提前提出部位、数量和所需时间，平台按订单协调自有产线进行分割并按约定时段组织配送。以全流程可追溯为建设目标，将来源、分割与订单信息衔接起来。
- **按需准备，线上不压待售库存**：我们不走「线上囤一堆肉慢慢卖」的路子，而是让真实需求去匹配产线产能。
- **临时起意的补充路径**：计划之外的需求，拟通过线下菜市场调配，或由专人前往屠宰场一级市场挑选配货，并如实说明来源。
- **异常分流机制**：预约订单若最终无法正常履约，对应肉品拟转入线下菜市场肉档销售——这是运营侧的损耗去向安排，不代表线上的无条件退改承诺。

## 三、还没定稿的部分，如实留白

一个有深度的品牌，不需要用半成品假装已经完成：

- **品牌名与主标志尚未定稿**：此前围绕「折叠面」「太平鸟」「纸翻花」做过多轮意象与命名探索，留下了重要的审美证据与反例，但尚无最终胜出的主名与主标。
- **视觉与字体仍在真实验证中**：金黄与橙红的暖色方向、四角色字体组合（香萃潮汐宋、FandolSong、Instrument Serif、Cormorant Garamond D3 原件）已完成原型对比，但印刷色值、窄屏长标题、价格数字回退与实物肉品标签仍需联合实测。
