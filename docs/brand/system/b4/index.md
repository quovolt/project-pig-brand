# B4 · 一套设计怎样留得下来

排版试验台得到认可之后，我们没有马上继续添加更多样式。新的问题是：**这套品牌怎样持续表达，而不只是这一版做得好看？** 比如再过半年，换一个没参与讨论的人做肉品标签，他找得到对的字体、能判断哪行必须先被看见，也知道换纸张或字号时该拿什么来验证。这才算从一件样张走向一套可以交接的设计。

## 把试错留下来，比只留最后一张图有用

过去几轮已经遇到三个容易混淆的判断：故事动人不等于可以直接从中取名；一个眼位有神不等于整枚标志成立；大画幅上的颜色和排版好看不等于标签印出来也好读。后来整理出 **34 条设计规则和 43 个历史回归用例**，分别记录故事与命名、视觉表达和主标的纠偏。它们告诉接手人当时为什么叫停、下次要用什么反例再检查，不是 43 个已通过的测试。

下一次比较要留原样、改动和结果。例如只动数字字重，其他条件先不变，才有依据说读不清的问题来自哪里。团队偏好、内部盲评、真实顾客是否看懂、实际尺寸是否可读、是否有权使用，回答的都是不同的问题。做到了哪一步就记哪一步，不让一种认可替另一种验证。

## 从「找得到源文件」到「别人做得出来」

恢复字体时，D3 是个现成的例子：原试验台写的是 500，字体内部却还有 Light 命名，只拿到一个「D3」或「Medium」的名字，接手的人很容易下载另一份。恢复原试验台的 HTML、CSS、字体和许可，保留原文件、用法和来路，才知道那版是怎么做出来的。图形也是一样：有成图，还要有可重做的几何与辅助线；有了源文件，还要有它在哪些尺寸、背景和介质下可用的证据。

因此，交付要按具体版本说清：这份源件是什么、什么场合可以用、需要怎样的内容与许可、哪些限制仍未验证。再交给没参与过的人，用真实内容、实际尺寸做一次，不靠原设计者在旁解释。现有的是源件、许可、样张和判断记录；生产级主标包、实物打样与独立交接还没有完成。

## 一处变了，先找到被影响的地方

假如某个字体后来不能用于一个新载体，先隔离这个用途，检查原许可和它在 B2 里的职责。用同一份内容、字号和版宽比较替代，再复测用到它的地方。旧版保留来路和禁用范围；如果已经印刷，还得另行处理物料，不能以为回滚文件就能回滚实物。这是一次回退演练，不是发现了新的字体授权问题。

同样的原则也用在发布上。草稿、候选和准许生产是不同状态，批准某版本的某个用途，不意味着同名文件都可以放出去。例外要留下用途、负责人、到期与复核条件。现有方案只把经过审阅的必要内容放进站点，内部源件和未审授权材料不随文档发布。上线后的观察，以后还要有可比较的基线、触发调整的信号和明确的负责人；目前没有监测结果或实际下线演练。

B4 可以交付的时候，接手的人知道该用哪一版、为什么、怎样做出来，也能找到谁验证过什么。没人验证过的地方，要写明还欠哪一步。
