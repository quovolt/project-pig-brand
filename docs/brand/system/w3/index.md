# W3 · 创意转化

**现在要做的，是把我们相信的事做给人看。** 「不替人做主」很好懂，但写成一句广告还不够。一个不知道背景的人，能不能从画面和服务里也察觉自己还有选择？W3 就在品牌定义和表达之间做这项比较。

## 从什么开始，最后要选什么

这里说的「创意机制」，指同一个想法怎样实际改变一句话、一张图和一个动作。比如「订单照常，晚饭可以改主意」，不光是一句话，还要求页面把两个状态分开。

动手前备好三样：[B1 的优先处境和角色](../b1/definition)、一项可核事实或明确标识的设想、已有视觉和语言对照。固定要解决的矛盾，不提前固定物件、名字或答案。

| 节点          | 怎么做                                                                                                                     | 留什么，失败往哪退                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| C1 拆关系     | 从动作、触发点、谁作主及后果开始。保留原物却移除作用，换成别的物件却保留作用，两次做对照。                                 | 留可被反驳的机制，不留「高级」「有生命力」当解释。解释不了差异，回原场景找观察。                 |
| C2 做跃迁     | 先写这轮改的是权责、用途、价值尺度还是感知主次。定向练习可以有题材；开放发散不给旧故事和旧名。                             | 至少两个会导致不同设计决定的命题。换同义词、材质或摆件不是两个机制。                             |
| C3 一核三投射 | 每个方案都做三件事：写一句这里真会说的话，画出信息怎么排，再让人实际做一个选择。保持对照的信息量、事实、触点和完成度一致。 | 留样稿、最强反例、无题解的观察。意图和实际首感分开填；内审不等于消费者证据。                     |
| C4 裁决       | 在另一场景找迁移，检查原角色、可兑现性和误读。区分秩序相同、不同机制，以及只在艺术中有效。                                 | 通过比较才交给 B2 做名字和标志；没有合适的就先不选。只在一个场景有效，也可以留作那个场景的办法。 |

## 一次旧案重放

纸翻花有用的不是「翻」或「花」。如果人只是按指令把花翻开一次，形还在，主动探求却没了；换成自己做饭，做好就能停，却愿意多试一下，原物没了，关系仍在。由此保留「人自己选择何时开始、何时停下」作为一个机制来源，而不把蜂窝造型交给 B2 当成必用标。灯笼也一样：亮光跟着人走，和人必须走到灯下面，是两个不同关系。若拿掉这项差别故事仍成立，它只是一件道具。

曾把好故事直接推成名字、把形体局部成熟当成主标起点；两者没有证明同一个创意能贯穿顾客经历。这就是为什么保留作品，却重开 C2–C4。

## 同题对照，留待试作

同一场景：一个已确认的订单不变，吃饭的人晚到。用三个方向检查「谁减轻了谁的负担、谁还能改变什么」。以下是可重跑的模拟，不是功能，也未做受众测试。

| 对照             | 一句话                                           | 视觉关系                       | 行为及反证                                                                                                   |
| ---------------- | ------------------------------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 商家承担算账     | 「这份按下单时显示的金额。」仅用于事实成立的样张 | 金额跨屏位置与层级稳定         | 能直接核对而不用猜优惠；若被读成跨日价保，退回事实与文案。它也可能只够做服务基线。                           |
| 当事人可以改主意 | 「食材订好了，怎么做可以晚点想。」               | 确认的订单与可改的个人便笺分层 | 改或删除便笺，订单不动；若用户以为编辑会改订单，退回分层与动作。                                             |
| 同伴也能参与     | 「我晚点到，给我留一口锅边的。」                 | 同层两条署名意见，与订单条分开 | 买家可以按对方意见改做法，也可以不采纳。把对方的话替换成「收到」当负例，检测改变来自内容还是界面上多一个人。 |

试作先问「这里发生了什么、谁能改变什么、订单是什么状态」，再比口头复述与第二场景。当前**没有胜出的母题**；回到 B1 只需按试验涉及的事实短回查。详见[内部工作底稿定位](../replay#原稿对照)及 [B2 构造图](../b2/)。
