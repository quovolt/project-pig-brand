# 品牌工程骨架

> 品牌的塑造不是凭空冒出来的，而是从商业命题出发、按顺序一步步推出来、验出来的工程。

这里是 Project Pig 的**内部推导与治理体系**。对外怎么把这份深度优雅地讲给人听，看第一部分[藏锐路径（信息披露与叙事范式）](../narrative/paradigm)；这里记的是每一个判断**从哪来、凭什么成立、边界在哪、以后条件变了怎么局部重推**。

## 商业底座：为什么不走「卖好肉」的老路

传统生鲜和肉品习惯大卖场式的叫卖——拼命喊肉好、新鲜、便宜，拉着人来挑拣、比价，买完就走。这种生意留不住人，最后只能卷价格。

Project Pig 的整套工程，是沿着另一条路往下推的：

- **靠理念和生活企划做复购与黏性**：用「生活，向未定之处生长」吸引气味相投的 Generation Z 和城市生活者，靠「生活主理人」企划融入日常一餐，让人因为合拍、省心、有意思而一次次回来，而不是只图一次便宜。
- **把供应链藏成压舱的真功夫**：自有 4A 产线按需分割、线上不压库存、当日固定挂牌价，是让这段长期关系不翻车的硬底气；对外走[藏锐路径](../narrative/paradigm)，埋在不经意处打消顾虑、增加探索深度，绝不拿来当菜市场喇叭喊。

## 有序推导骨架

品牌从上游定义到下游交付按依赖顺序展开。后面哪一环出了问题，都能顺着链路退回对应的地方局部重做，不用推倒重来：

```text
商业判断（靠理念与企划做黏性和复购 · 供应链作压舱底气）
  │
  ▼
B1 · 品牌定义        想清为谁做准备、扮演什么角色、提供什么价值、边界在哪
  │
  ▼
W3 · 创意转化        固定真实场景，在「话语 × 视觉 × 动作」里比出真机制（当前关键关口）
  │
  ▼
B2 · 品牌表达        把过门母题落成语言、视觉、字体、命名与主标志，并联合验证
  │
  ▼
B3 · 体验与履约      让小程序交互、双供给路径、价格和异常规则与真实能力逐项对上
  │
  ▼
B4 · 交付与维护      沉淀规则、回归案例、源文件与回退机制，确保换人也能接得住
  │
  └── 对外投射为 ──→ 藏锐路径（一瞥名标视觉 → 上手交易灵感 → 核验检疫规矩 → 溯源自有产线 → 认同生活主理人）
```
