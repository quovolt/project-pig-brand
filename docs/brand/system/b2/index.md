# B2 · 品牌怎样被看见

「生活，向未定之处生长」落到一张画上，最初难的不是找一种漂亮的风格，而是让**秩序和生命力在同一张图里成立**。一张海报可以有想象力，一张肉品标签要让人判断这是什么，一条订单提醒则要讲清接下来怎么办。三者不必一样热烈，但应该能认出是同一家。

## 留住认得出的地方，换掉最值得换的那一处

我们试过让叶子、桌面和窗框把一张图稳住。那张画有秩序，却也让人觉得接下来不会发生什么。被认可的地方反而是色彩像生命力一样挥洒泼溅，线条和配色又相互照应。再往下推，「未定」就有了更具体的意思：不必处处符合物理规律，也不需要靠杂乱来证明自由。

后来用更小的动作来试：保留食材、器物或一个能认出来的动作，只替换最值得表达的那一处。热气可以离开写实的形状，去承担滋味和动势；其他部分仍让人知道自己看见的是什么。于是「真实」负责认知，「虚」可以把看不见的感受带出来。画面里若有变化，读者应该有东西可以抓住，而不必靠说明才看懂。

金黄和橙红被留下，是因为放进切肉、端碗等不同场景仍有一条可以继续发展的暖色主线。明暗先拉开重点与余地，颜色再传递温度和动势，肌理给局部增加触感，不和价格、规格等信息争位置。去色稿和色组试验帮我们问清这些各自做了什么；局部亮度数据不是整幅图的阅读结果。我们没有据此确定统一中灰、固定配色比例或印刷色值。

## 一套字体要有不同的人做事

最早保留 E＋B，是因为宣传标题有性格，标准用字又能稳住它。继续比较后发现，光有风格共振还不够：有些标题字显得幼态，而标准用字是品牌的正式门户，既要有审美，也要能安静地承担商品说明和交易信息。这是为什么后来选了**潮汐宋做中文宣传标题，Fandol 宋做标准中文**，而不是让两套字体都负责出彩。

英文用 Instrument Serif 辅助，视觉上不压过中文。数字曾经不够协调，比较后以 D3 为主。找回的排版试验台用的是 Cormorant Garamond，CSS 和文件字重都指向 500，但文件内部仍有 Light 命名。保留实际样张所用的原文件，不按名字猜测并替换。试验台给了我们一套可回看、可比较的组合；窄屏价格、长标题、货币符号回退、实机和印刷还要拿真实内容验证。样张里的字号不是规范。

## 先说想传达什么，再看别人收到了什么

命名和图形之前，我们把两个问题分开：**我们希望别人怎样看待我们；一个没听过故事的人，实际会先感受到什么？** 一个标志可以有耐读的来历，但第一眼仍要有清楚的主体与姿态；专业也不能只靠技术感来暗示，否则容易被读成冷淡。这个区别后来同样用在文字上：宣传可以大胆邀请，选购先讲事实，订单改变先讲状态与可行选择。「适应变化」若被读成无条件兜底，就不算传达成功。

折叠面有空间巧思，却很难第一眼说出像什么；给它加材质、补故事都解决不了。磨砂、雾面和电镀打开了背景的虚实，用户明确不希望它们去承担主图标。太平鸟让我们找到另一条路：不要求人人立刻认出鸟种，但得先读到一个有神采的鸟形，愿意深挖的人才进入它的来历。E4 眼神和早期月牙肩型在局部成立，后续反复修改身躯、甚至把所有特征都塞进去，没有得到一枚合适的标志。

纸翻花则从另一条路出现：人有了一段不必交代用途的时间，做着做着还想再做一会儿。它和自己做饭可以是同一件事的不同表达。它的开合能随形体改变；画面要试的是外面的光穿过完整的蜂窝网格，而不是照在花上，或只让一个孔亮起来。概念图没有通过；这只留下一个值得推敲的意象和几个明确反例。命名里，故事说得动人、词能概括心情，都不能替代裸听、好记、画面、语境与误读的检查。**太平鸟、纸翻花和曾经的候选词都不是定稿。**

现在有的是一套可比较的表达基线：色彩与虚实方向、排版原型、字体分工，以及说话时的分寸。下一步先在 [W3](./../w3/) 用同一情境比较创意，再让成立的方向分别接受名称与图形的检查。最终要把候选放进同一组小程序首屏、肉品标签和订单状态，看是否认得出是同一家、能否读懂并完成眼前的事。现阶段还没有这样的联合通过稿，也没有受众、印刷或正式权利核查结果。
