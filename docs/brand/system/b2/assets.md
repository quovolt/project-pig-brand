# B2 · 概念图与字体原件

这里放的是当时做过的图和实际排过的字。概念图是用于讨论设计的图像，不是实物照片；比较样张里的内容、价格、字号都不是经营或生产规范。

## 概念图

[![原三触点画板：烹饪主画面、商品与服务界面](/b2/concepts/three-touchpoints.png)](/b2/concepts/three-touchpoints.png)

**早期三触点画板。** 同一套表达落在主画面、商品和服务上，表现力度各不相同。另存的[餐桌主画面](/b2/concepts/early-table-study.png)可放大看色块与线条怎样相互牵引。

[![热气化作金黄与橙红的半透明色层](/b2/concepts/b2-steam-substitution-v1.png)](/b2/concepts/b2-steam-substitution-v1.png)

**热气的艺术替换。** 手、夹子、锅与食物仍然可辨。热气离开写实轮廓，承载了滋味与动势。这是当时认可的样本。

[![两幅场景对照：切肉与端碗](/b2/concepts/b2-cross-scene-study-v1.png)](/b2/concepts/b2-cross-scene-study-v1.png)

**切肉与端碗。** 这是换场景后的迁移试画，不是逐幅确认的成品。两幅图仍沿用了相似的暖色层和笔触，因此不足以证明方法换任何题材都成立。

[![开窗的手与陶盆，墙上的暖色枝叶](/b2/concepts/b2-window-shadow-v1.png)](/b2/concepts/b2-window-shadow-v1.png)

**窗前的影子。** 用窗、手和陶盆维持认知，让墙上的投影成为可替换的部分。当时认可它与热气图的风格亲缘；不能据此断定每个人都会把墙上的色块读成影子。

[![植物与不遵循现实受光关系的放射状枝影](/b2/concepts/b2-undetermined-shadow-v1.png)](/b2/concepts/b2-undetermined-shadow-v1.png)

**未定之影。** 进一步放开窗框和枝影的固定关系，试着让「未定」来自意外的空间走向，而不是把画面打散。另有[色组对照原图](/b2/concepts/b2-palette-comparison-study-v1.png)，用于回看金黄与橙红，不是正式色卡。
