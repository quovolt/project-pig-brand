# B2 · 做过什么，为什么这样选

### 局部重放：数字字重无法复现

如果原 D3 无法用规范字体环境复现，先锁同一中文、英文、价格、列宽与字号，仅替换数字实现。检查长短价格、位数变动、小数点与单位、实际墨迹和字体回退。能读清、对齐且观感接近，再更新 P3，并复测 P5 中受影响的触点。**无需重选中文字体、改配色或重开理念。** 这是演练，尚未选替换字体。

### 局部重放：主形缩小后无法识别

先关闭颜色、肌理和动效，比较单色及反白的实际使用尺寸。若原整鸟清楚但简化后失去姿态，回 P4 重建骨架及取舍，不回 W3；若不同图形和语言都持续暗示品牌替人作主，再回 W3 检查机制。例子是审查路由，不是此次进行了新识别测试。
