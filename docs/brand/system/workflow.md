# 怎么做，哪里要重做

做品牌不必一口气解决所有问题。先想清我们愿意替人承担什么，再找一个真实场景，把这个选择做给人看。每一轮只加一道难题；想到一个大胆的办法，可以马上试，不必等所有部件都定下来。

1. **先把事实说清。** 如果要试「顾客临时改约」，先分清晚饭改做法和订单改时段。后者能不能改、要不要付费，不能从品牌态度推出来。没拿到规则，可以在样稿里标成假设。
2. **弄清是什么让人有感觉。** 把纸翻花留在故事里，却让主人公只按指令翻一次，原来那点乐趣还在吗？再换成做饭，看她随时可以停，却自己又多试了一步。能解释这种差别，才知道该保留的是自由尝试，还是某个具体物件。
3. **用同一个场景比不同办法。** 各做一句真能用的话、一种能重复的排法、一个人能做的动作。让没读过说明的人先说自己看到了什么。跨场景都讲不清，回到创意本身；只在一张海报上有效，就先当海报的好办法。比整体用同样的事实和完成度；要查哪一步起作用，再只改一个变量。
4. **分开试名字和标志，再放到一起。** 名字先只听声音，看能否复述、是否串到别的行业；标志先关掉颜色和效果，在实际大小看还能认出什么。故事可以加深印象，不负责解释一眼没看懂的图。名字不顺口就改字，轮廓不成立就回去调整形体；两件单看都好，放在标签上读不清价格，就重排标签。
5. **拿实际内容验，交给别人试。** 加进长品名、价格、日期、限制与订单状态，查读者先看到什么、记住谁、下一步会点哪里。样张说明设计能否读懂，不能证明后台做得到。正式使用前另查运行事实、实物效果、权利和许可。

开放找点子时别先透露旧答案；评议时也别提前讲故事。意见不一致，先看看两人究竟看见了什么。内部读稿不冒充消费者测试；审美上喜欢，也不能抵消对价格、责任、名称或图形的严重误读。

每次留下四样东西：**用的是哪版材料、改了什么、看到什么、接下来怎么处理。** 和上版比较时，既查问题有没有改，也查做对的部分有没有被改丢。完整规则与用例在[原稿索引](./replay)所列的本地工作档。
