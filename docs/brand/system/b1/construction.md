# B1 · 怎样分工

说「我们想做一个肉品品牌」还不够。先得回答：谁现在遇到了什么麻烦，我们愿意接过哪一部分，又有哪些事该由他自己决定？B1 把这几个问题分开。每答清一个，后面就少猜一件事。没答清也可以做草稿，但要看得出哪里仍是假设。

## 怎么组装

```text
具体处境 + 现有做法 + 能力起点
               │
        B1.1 选问题与位置
               │
          优先处境与取舍
           ┌───┴───┐
           ▼       ▼
    B1.2 定价值    B1.3 定关系
      与兑现边界     与行为分寸
           └───┬───┘
               ▼
        B1.4 排信息层级 ──→ W3：用选定关系做创意对照

  定位 + 价值 + 角色 ──→ B1.5 定义署名与责任
  信息层级 + 署名责任 ──→ B2／B3 说话、做事
```

B1.2 和 B1.3 可以并行发散、彼此改写，但需要共同接受一次核对：**角色想做的事不能超出真实能力，能力也不自动规定角色。** B1.4 等两条支路都有东西可用才排优先级。B1.5 可先画最小关系图，与信息层级对齐署名；单品牌阶段不因拆出服务模块就增加子品牌。五个编号沿用 World Map，箭头是 Project Pig 的交接方式，不是固定的时间表。

## 各模块怎样做，而不只是交表

| 模块                                           | 操作与出口                                                                                                                 | Project Pig 用什么试                                                                                                                       |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **B1.1 现实诊断与定位取舍** · 选哪道题         | 并排写出现有做法、它哪儿有效、哪儿仍让人花力气；再定优先处境及本轮不做什么。交给后面一条可比较的定位，而非泛泛的人群画像。 | 把晚下班的人随买、点外卖、提前备餐并排。优先服务仍想自己决定怎么吃、却不想承担全部准备的人；不拿普遍存在的急单当品牌主轴。替代比较待验证。 |
| **B1.2 价值主张与承诺边界** · 凭什么做到       | 把每项价值写成「帮助对象做到什么 → 由什么支撑 → 何种条件下不成立」。产出主张与证据对照，未核事实同时传给 B1.4 和 B3。      | 「让变化得到回应」分成可说明现有选项与能否实际改约。前者可以是设计原则；后者要查容量、截止时间、费用与责任，不能写无条件兜底。             |
| **B1.3 理念、人格与关系调性** · 以什么关系介入 | 对同一情境摆出两种以上做法，写清冲突时何时主动、何时退后。允许从艺术或生活细节反推新关系；发现影响价值定义时回给 B1.2。    | 「生活导师」会替人规定怎么吃，「被动工具」在该承担责任时不出声。选「需要时靠得住，平时不抢戏」，同时容许共同主理。                         |
| **B1.4 信息层级** · 同一立场在不同场景怎么说   | 拿一条已界定的价值和关系，排出主张、支柱、证据、条件、行动；按触点选择哪一层先出现。交出信息顺序，不先写完广告词。         | 品牌内容可以先讲「认真准备，让生活尽情发生」；订单状态则应先讲有无确认、当前可做什么与限制。两种语序没有改变立场。完整信息屋待按场景对照。 |
| **B1.5 品牌架构与命名层级** · 这些事由谁署名   | 画主品牌、服务与内容的关系，先问是否共享信任与承诺，再决定共用署名或单列。交付责任关系与命名层级，名字本身在 B2 验。       | 主品牌承担信念与信誉；「生活主理人」是其下服务企划；预约供给、临时响应和内容是模块。暂无需要另起子品牌的独立责任边界。                     |

## 用一条订单提醒检查这些决定

假设同伴说想晚一点吃，配送订单暂时没变。提醒要先告诉顾客订单是不是照常，再说明哪件事可以调整。顾客如果把聊晚饭当成已经改了配送，先看页面有没有把两件事说清楚。如果页面本身许诺能改，再查店里是否真做得到。这样能知道该改文案，还是得重审服务承诺。

[回到 B1 的五项成果](./)

- [定义与进出门槛](./definition)：看今天采用的决定、已知与未知。
- [推导与取舍](./derivation)：看真实项目经历了哪些转折，以及为什么改。
- [交接与复核](./handoff)：拿决定号去做 W3、B2 或 B3，发现冲突知道退回哪里。

构造图管模块和依赖，定义页管结果，推导页保留证据。**模块数不等于页数。** 随工作需要展开某块，保留入口的全局关系，不用靠增加文档制造进度。
