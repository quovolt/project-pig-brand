# B1 · 交接与复核

开始做创意之前，先带走两条已选定的分寸：品牌负责把准备做清楚，决定怎样过这一餐的仍是当事人。至于用一句话、一张图还是一个服务动作来表现，留给下一轮比较。遇到不能确定的服务条件，回到最有可能证实它的人和材料。

## 把定义变成能用的输入

| 交给谁      | 交出的约束                                                                                                       | 怎么检查                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| W3 创意推导 | 由 D1、D2 出发：准备减轻本不该由用户承担的负担，但不代替用户决定一餐。固定一个现实矛盾，允许比较不同的跃迁机制。 | 是否有两种真正不同的设计选择？在话语、视觉和行为中，是谁在做决定？若每案只换词或同属一种机制，退回解构。 |
| B2 表达     | 由 D2、D4 出发：内容可有独立的艺术主张；涉及买卖和履约，先清楚说事实与动作。由 D5 决定谁在署名。                 | 不给解释做首读，分别问「谁在提供什么」「什么仍由我决定」。不能靠海报好看盖过读不清事实。                 |
| B3 体验     | 由 D3、D4 出发：把「回应变化」拆成条件、去向、时限、费用与责任。                                                 | 用真实服务规则核实每条对外说法；未核实的一律不写成可用能力。                                             |
| B4 维护     | 保存定义版本、支持证据、边界与需要复查的信号。                                                                   | 能否从一个公开说法反查到对应定义与履约依据？不能则删掉说法或补证，不以资料存得多作为验收。               |

## 小例：加班晚了，晚饭改主意

- **事实回查**：先区分「今晚怎么做」和「配送能否改」是两个问题。若样张里有确定的订单状态、价格或时段，标明是已核事实还是模拟。当前不由 B1 推定有改约、退款或价保。
- **创意题**：如果已确认的订单不动，品牌还能怎样让人有机会改变自己的安排？例如当事人自己作决定，与同伴协商后改变做法，是两种关系，不是两句同义文案。这只是 W3 的可比测试条件，不是已经选择的功能。
- **验收预期**：不用解释，读者能各自指出什么没变、谁改了什么。若读成「改一下晚餐就能随时改订单」，先查触点怎样混淆了两种状态；若服务宣称本身无法兑现，回 B1／B3 校正承诺，不修辞。

## 哪些事会重开 B1

1. 替代选项对照和真实用户反馈动摇了优先处境或价值排序。
2. 业务核验改变了支撑条件，例如来源、追溯、价格或变更范围与企划不同。
3. 多个不同的语言、视觉和行为样本始终引导出同一反向理解，例如读成品牌替用户作主；先排除单件表达失误，再开上游定义。

反之，名字拗口或一张图不好看，不足以重写理念。更新时沿用 World Map 的同一张工作与决策记录卡，写明证据与受影响的决策号，并回查使用该决策的下游稿件。

## 怎样保留一个可以重放的决定

**决定号标识问题，版本标识当时的回答。** D4 始终指承诺与表达边界；D4 的具体条件可以随证据变化。沿用同一张工作与决策记录卡，记下：哪一版输入、用什么操作从条件推到结论、对照过哪条替代、为何放弃、哪些产物引用了这版、什么信号会迫使重审。仅留「我们决定了什么」，无法知道换了条件以后答案是否仍成立。旧版保留当时的适用范围和失败证据，现行入口只指向当前版本，不用覆盖历史。

重推的次序：**换输入 → 重跑对应判断 → 比较新旧答案 → 沿依赖复测 → 再切换现行版本。** 若结论没变，只添加新证据；若变了，只替换受影响的节点和下游，不重做无依赖的工作。已经对外使用的内容另记更正与实际影响，不能只换文件。

## 重放示例：变更规则变了，其他结论要不要重做

历史上已从「兜底」收回到「适应变化有边界」。以下为**反事实演练**，不更新现行服务：假设运营后来证实，超过某个截点无法改配送时段。

| 重放动作             | 推导结果与影响                                                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 只替换输入           | B1.2 从「能否变更待查」替换为「截点后不可改时段」。把该条件和出处记在 D4 的候选修订；不把一条例外扩写成任何时间都不可变。                                    |
| 用原来的选择逻辑重推 | D3「让变化得到回应」仍成立，但在该场景中，回应只能是主动说明限制与可用选项，不能把换时段继续作为选项。若连续多场景实际无任何选项，再重评这条价值的适用范围。 |
| 只复测受到影响的产物 | B1.4 把时段限制提到行动前；B2 复核受影响文案是否暗示可改；B3 检查服务规则与按钮是否一致；W3 仅回看把「可改订单」当机制的候选。                               |
| 保留未被推翻的部分   | B1.1 的优先处境、B1.3 的合伙人角色、B1.5 的主品牌与服务关系不必重做。在不改订单的前提下，晚饭仍可以由人自己决定或共同商量。                                  |

这次只演练结构能否局部重放，不声称已经取得运营证据或批准新版本。
