# B1 · 推导与取舍

我们最早在讨论怎么买到合意的肉。后来才发现，准备工作越可靠，生活反而越不必按计划走。下面按这个判断怎么长出来的顺序写。中间走过弯路，有些答案也是画出来以后才看见的。

**业务原点 → 处境与矛盾 → 展开不同的关系 → 用审美发现反推 → 挑明取舍 → 形成有适用范围的工作定义。**

| 推导动作                          | 用了什么、为什么这样推                                                                                                                                                             | 改变了什么                                                                                                                             |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 从生意里找矛盾，而非抄服务方案 | 下班后选购的时间和判断成本高，仍希望吃到自己想吃的。肉品供给、预约与明确价格给协助一个现实支点；它们不能解释人为什么在乎这顿饭。                                                   | 把「更方便取得食材」与「怎样过这一餐仍由自己决定」分开，找到准备与自主可以并存的机会（D1）。                                           |
| 2. 从人群标签拆到共同处境         | 最初的年轻上班族故事很具体；把年龄和家庭结构替换掉，看哪种需要仍成立。独处者、伴侣、双职工家庭未必有相同时间表，但都有可能既有自己的想法，又不想独自承担全部准备。                 | 以处境定义优先对象，不靠把所有人纳入来扩大品牌。以上是项目判断，未作样本验证。                                                         |
| 3. 让不同想象竞争                 | 「生活创作室」「城市共同餐桌」「日常工坊」分别问：食材能不能是创作材料？谁能共同决定？技艺怎么进入日常？它们先作为视角，并非候选名称。                                             | 把启发、共同创造、专业技艺都引入，避免把品牌越推越像一份采购清单。也不把其中一种生活方式强加给所有人（D2、D3）。                       |
| 4. 从审美结果倒推立场             | 「食材的近距离 × 正在发生的滋味」让人既看清材料，又感到变化；「会扩展的桌面 × 可以即兴的节奏」让人既可相聚，又保有各自空间。问的是两个关系产生什么新感受，不是选一张好看的画定调。 | 第一组把专业从供货口号推到能唤起感受与创造；第二组把「主理」从个人掌控扩到协商。它们反过来修改 B1，不是给旧定义配插画（D1、D2）。      |
| 5. 用反例划出角色                 | 「值得信赖的肉品供给」准确但只说了能力；「专业，带来选择」逻辑有用，却说不出是谁的生活、为什么值得选择。生活导师会指导过多，隐形工具在该出手时又失位。                             | 信赖、专业继续做底座；主张收敛为认真准备之后，生活仍有未定的可能。关系收敛为「需要时靠得住，平时不抢戏」，不借低调逃避责任（D1、D2）。 |
| 6. 区分表达、服务、证据           | 以「加班晚归、计划有变」为反例：品牌可以说明当下能做什么，但无法从温度直接推导任何时候都能改、退或送。事实要按业务能力验证；想象力则可用于呈现生活的未定。                         | 保留有边界的回应，撤去「无限兜底」的解释；保留理念正文，另列条件与待证项目（D3、D4）。                                                 |

D1–D5 的现行口径以[定义页](./definition)为准。D5 是根据当前主品牌、服务企划与模块职责做的阶段性组织决定，不由上表的审美推导证明。
