# B1 · 品牌定义

**B1 v1.0 是目前用于推导的内部定义。** 理念正文保留原版；这里把团队现在可调用的选择、边界和待验证事项列出来。不把工作共识当作市场发现或上线承诺。

> 生活，向未定之处生长。
>
> 一切经过认真准备，故事却仍然由生活继续写。

## 什么时候进入 B1，交出什么

**B1 把一个现实机会变成有取舍的品牌定义。** 先问顾客的哪一种处境值得我们介入，再决定品牌在这段关系里负责什么、主动放弃什么。业务方案给出约束，审美和生活观察可以改写理解；最后要落成可约束设计与行为的选择。

| 入口材料                                         | Project Pig 的实际输入                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 一个具体的人、情境与摩擦，能说清对方今天怎么解决 | 忙完工作仍想按自己的心意吃一餐，但采购与准备耗精力；现有做法可以是下班再买、临时点外卖或提前备好。痛点源自创始故事，替代方案还未系统比较。 |
| 一个可查的能力起点，以及事实、设想和未知的区分   | 从肉品供给出发；预约匹配供给、同日挂牌价稳定等是企划设想。规模、追溯和变更条件需验证，不能由创始故事直接推出承诺。                         |
| 一个必须做出取舍的品牌问题                       | 我们只把买肉变得省事，还是也要帮人保留决定这一餐的空间？品牌负责准备到哪里，又在哪里退后？                                                 |

**进入门槛：** 能指出场景、能力起点及待决定的问题，就可以开工。只有一个好词或一张风格图时，先回到问题界定与取材。样本量和运营数据不足时，照样可做内部推导，但把依赖它们的结论留作待证。

| 最低产出                                             | 这份文档里放在哪                                                                                      |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 优先对象、需要解决的张力，以及相对替代做法的定位取舍 | 下方「我们为谁做什么」与 [推导与取舍](./derivation)。当前定位是内部方向，替代比较待证。               |
| 品牌信念与角色、三项价值、明确不做什么               | 下方 D1–D3。每项须能改变一个实际选择，不能只剩理念句。                                                |
| 价值的真实支点、承诺的边界、主品牌和服务关系         | 下方 D4–D5 与 [交接与复核](./handoff)。保留待核事实，不把它们变成下游可引用的承诺。                   |
| 可交接的下一题、所用证据和复核条件                   | [推导与取舍](./derivation)保留依据和被舍弃的方向；[交接与复核](./handoff)给出 W3 的输入、用例和回退。 |

**出口门槛：** 接手的人不必听设计者讲完整故事，就能说清为谁、选了什么、拒绝什么、依据在哪，并用一条具体场景判断什么只是表达、什么须由业务兑现。Project Pig 的 B1 v1.0 可以带着已标明的未知进入 **W3 内部创意对照**，尚不能作为市场定位已验证、履约承诺已上线或对外口号定稿的依据。品牌名、商标和完整表达规范不属于 B1 的出口。

## 我们为谁做什么

有人下班后想烧个喜欢的菜，却不想再为挑肉、比价和安排配送费心。我们从肉品供给做起，帮人把这些准备做得轻松一点。独居、两个人一起住、双职工家庭都可能遇到这种时候。还需要验证的是，这种处境有多常见，我们又比他们已有的选择多做了什么。

## 定义基线

| 决策          | 现行定义                                                                                         | 会改变的选择                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| D1 价值立场   | 认真准备与生活自主可以并存。准备的价值是让人有余地做自己的决定，包括临时改变或什么也不安排。     | 不把「每餐必须计划、尝鲜或做得漂亮」当成成功；同一种可靠供给应能支持想尝试和想省点力的两种用户。                   |
| D2 关系角色   | 需要时靠得住，平时不抢戏。专业帮助在需要时主动递上，决定权留给当事人；一起吃饭也可以一起商量。   | 对订单事实和可行选择作明确说明。不替顾客安排生活，也不在品牌该承担责任时消失。                                     |
| D3 价值结构   | 让期待有所依靠、让变化得到回应、让新的念头有机会发生。                                           | 第一项靠真实供给与清楚信息；第二项靠有条件的响应；第三项靠自愿的灵感与尝试。不能用一句「我们懂生活」替代三种行动。 |
| D4 承诺与表达 | 适应变化不等于兜底。艺术可用虚实传达感受；选购、改约和异常处理的事实必须准确。                   | 不把企划写成已上线能力；不以诗意或亲切语气掩盖规格、价格、时限、费用、责任或限制。                                 |
| D5 身份关系   | 主品牌负责信念、信誉和关系；「生活主理人」是主品牌下的服务企划；预约供给、临时响应与内容是模块。 | 不另立子品牌，不把项目代号、企划标题或理念句当成最终主品牌名。                                                     |

「我们认真准备，让生活尽情发生」可以概括态度，不要求每个触点重复。原版理念全文、细化的供给设想和当时的措辞留在本地工作档，有意与当前定义分开。公开前仍需审阅。
