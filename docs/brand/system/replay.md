# 产出重放索引

想查一个判断怎么来的，先从下表找到它属于哪块，再去看当时试过什么。旧稿仍有用：它能解释上次为什么没选这条路，也能帮我们判断，条件变化后要不要再试一次。

| 构造入口         | 进入条件                                         | 当前接得住的工作                                         | 重开信号                                          |
| ---------------- | ------------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------- |
| [B1 定义](./b1/) | 有场景、能力起点与真实取舍                       | 工作定义可以用于内部推导；市场和经营证据待补             | 对象、真实能力或关系判断变化                      |
| [W3 创意](./w3/) | 有 B1 约束、可对照场景和反例                     | 机制、旧案正反与三组拟试写法；没有胜出母题               | 不同表达反复造成同一种关系误读                    |
| [B2 表达](./b2/) | 有目标读法、媒介和事实；主识别收敛须再有过门母题 | 语言、视觉、字体和版式基线，命名和标志探索，联合验证未完 | 单件失败回部件；组合失败回联合；共同机制失败回 W3 |
| [B3 体验](./b3/) | 有用户任务、可查事实与条件                       | 原始企划、状态原型和待执行验收切片                       | 服务动作无法兑付、现实条件变化                    |
| [B4 治理](./b4/) | 有可追溯的工件、使用场景与证据                   | 能找到近来的档案、规则和旧试错；未完成生产与自治         | 权利、载体、证据或运行责任发生变化                |

## 整体更新时，检查有没有漏沿依赖走

每条现行决定都能指回当时的输入、替代、裁决和证据；每条历史稿都有用途（对照、反例或保留），不冒充现行口径。替换某项输入时用 [B1 的局部重放](./b1/handoff)、[B2 的数字与图形用例](./b2/replay)、[B3 的履约条件](./b3/) 或 [B4 的授权例外](./b4/) 复查下游。只重做受影响的判断，保留旧版适用范围。下一轮应以实际对照推进 W3，而不是再新增一组归档文档。
