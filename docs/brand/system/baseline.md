# 做到哪了

截至 2026-11-25，Project Pig 已有第一版[品牌定义](./b1/)：我们先做一个帮人省下采购和准备、仍让人自己决定怎么吃的肉品品牌。B1 已定下服务谁、品牌扮演什么角色、提供哪三种帮助、哪些事不能先答应，以及服务企划与主品牌的关系。客户和市场还要验证；「愿意回应变化」也不能直接写成「订单一定能改」。

我们试过用金黄和橙红画出一顿饭的生气，也试过怎样让标题有趣、价格易读。太平鸟和纸翻花留下了值得再看的试稿，但还没有定名字、主标和成套设计。想看具体取舍，读[表达试稿](./b2/replay)。

**下一轮先比较一件事。** 用同一张订单，看三种做法各自改变了什么：店里把账说清，当事人能改晚饭的想法，同伴也能提个主意。先让读者自己说看见了什么，再决定哪个方向值得做成名字和标志。现在只有[试作方案](./w3/)，没有测试结论。

[服务企划和验收例子](./b3/)还没跑过完整的实际服务；[原稿、规则和失败记录](./b4/)已归档，但不是生产包。需要追溯时，从[决定与原稿索引](./replay)进入。
